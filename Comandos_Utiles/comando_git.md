# 🐙 Introducción rápida a GitHub

## 💡 ¿Qué es?

**GitHub** es una plataforma en la nube donde puedes **guardar, compartir y colaborar** en proyectos que usan **Git** (el sistema de control de versiones).

## 🎯 Para qué sirve

- 💾 Guardar tu código online.
- 🧑‍💻 Trabajar con otros programadores.
- 🕓 Ver el historial de cambios.
- 🚀 Publicar tus proyectos.
- ✅ Revisar y aprobar cambios (Pull Requests).

## ⚙️ Cómo usarlo (básico)

1. Crea una cuenta en [github.com](https://github.com).
2. Instala **Git** en tu ordenador.
3. En tu proyecto local:

   ```bash
   git init
   git add .
   git commit -m "Primer commit"
   git branch -M main
   git remote add origin https://github.com/tuusuario/tu-repo.git
   git push -u origin main
   ```

4. Tu proyecto ya estará en GitHub 🎉

---

## 🧩 Conceptos clave

| Término          | Significado                      |
| ---------------- | -------------------------------- |
| **Repositorio**  | Proyecto en GitHub.              |
| **Commit**       | Guardar cambios.                 |
| **Branch**       | Rama para probar cosas.          |
| **Pull Request** | Solicitud para fusionar cambios. |
| **Fork**         | Copia de otro proyecto.          |

---

## 🧠 En resumen

* **Git** controla versiones en tu PC.
* **GitHub** guarda esas versiones online y permite colaborar.

---

**Consejo:** crea un proyecto pequeño y súbelo a GitHub para practicar 🚀
